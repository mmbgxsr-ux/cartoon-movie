# 🎬 صانع الأفلام الكرتونية

استوديو يعمل داخل المتصفح لصنع **أفلام تعليمية كرتونية متحركة بالعربية (باللهجة المصرية)**. ترفع خلفيات المشاهد ولوحات الشخصية، وتكتب نص كل مشهد، فيرسم المحرّك الشخصية وهي تمشي وتتكلم وتشير، ويصدّر لك الفيلم ملف MP4.

لا يحتاج خادمًا ولا تثبيتًا: كل المعالجة تجري في متصفحك، وبياناتك تبقى عندك.

## المزايا

- **15 خلفية** لكل درس، مع ضبط موضع وقوف الشخصية على كل خلفية.
- **لوحات الشخصية:** مشي، جري، تلويح، إيماءات، إشارة، تفكير، حزن، دهشة، فرح، جلوس، التفات.
- **تحريك الفم** متزامن مع الصوت.
- **الصوت:** توليد التعليق بمفتاح Gemini، أو رفع ملفات صوت جاهزة، أو الاكتفاء بصوت الجهاز.
- **الطاقم:** عدة شخصيات في الدرس الواحد وحوارات بينها.
- **لحظات القرار:** أسئلة تتوقف عندها الحلقة ليجيب الطالب.
- **محرر المشاهد** والمخطط الزمني للصوت والإيماءات، وشريط العصر والسنة على الشاشة.
- **قوالب العوالم (بدء سريع):** آلة الزمن (تاريخ)، رحلة مصغّرة (علوم)، رحلة سفر (جغرافيا)، باب الألغاز (رياضيات)، النص يتكلم (لغة عربية).
- **تصدير MP4** بدقة وبلا تقطيع (WebCodecs) مع دمج الصوت.
- **حفظ المشروع** ملف JSON، أو **حزمة كاملة .zip** (مشاهد وإعدادات وصور وصوت) تُنقل بين الأجهزة.
- تخزين محلي كبير السعة عبر IndexedDB.
- **إمكانية الوصول:** تبويبات تعمل بلوحة المفاتيح (الأسهم وHome وEnd)، وأسماء لكل الحقول، ورابط «تخطَّ إلى الأقسام»، وإشعارات تُقرأ بقارئ الشاشة، وأهداف لمس أكبر على الجوال، واحترام «تقليل الحركة».

## التشغيل السريع

الطريقة الأبسط: افتح `index.html` مباشرة في المتصفح.

أو شغّل خادمًا محليًا:

```bash
python -m http.server 8000
# ثم افتح http://localhost:8000
```

أو افتح نسخة الملف الواحد من `dist/cartoon_movie_vNN.html` بعد البناء (انظر أدناه).

> **المتصفح:** يُنصح بـ Chrome أو Edge الحديث، لأن تصدير MP4 يعتمد على WebCodecs.

## استخدام درس جاهز

في مجلد `lessons/` دروس جاهزة:

| الملف | الدرس |
|---|---|
| `fath_misr_lesson.json` و`fath_misr_lesson_v2_dialogue.json` | فتح مصر (نسخة بالحوار في v2) |
| `nizam_biaiya_lesson.json` | نظام بيعة (ومعه مجلد `nizam_biaiya/` للصور والصوت) |

1. افتح الصفحة، ثم تبويب **المشروع**، واضغط **📂 فتح مشروع أو حزمة**، واختر ملف الدرس.
2. ملفات الدروس تحمل المشاهد والخطة فقط. ارفع الصور من تبويباتها: **الخلفيات** و**البطاقات**.
3. ارفع ملفات الصوت (بترتيب المشاهد) من تبويب **التشغيل**، أو ولّدها بمفتاح Gemini.
4. للدرس «فتح مصر» خطة الخلفيات والبطاقات المطلوبة في `docs/fath_misr_plan.md`.

## البناء

الكود مقسّم إلى ملفات في `js/` و`css/`، ويجمعها `build.py`:

```bash
python build.py            # يولّد index.html و dist/cartoon_movie_vNN.html (مع تصغير إن توفّر terser)
python build.py --no-min   # بلا تصغير
```

- رقم الإصدار يُقرأ من ملف `VERSION`.
- ترتيب تحميل ملفات JS في `files.json`. الملفات تتشارك متغيرات عامة، فالترتيب مهم.
- **لا تعدّل `index.html` يدويًا:** هو ملف مولَّد من `index_body.html` و`files.json`. عدّل المصدر ثم أعد البناء.
- مجلد `dist/` ناتج بناء ولا يُتتبَّع في Git.

## هيكل المشروع

```
index_body.html   قالب الصفحة (المصدر)
index.html        مولَّد من build.py
css/styles.css    التنسيق
js/               وحدات التطبيق (render, mouth, audio, sheets, export, editor, ...)
assets/shimg.js   الصور الافتراضية المدمجة
lessons/          دروس جاهزة وملفاتها
docs/             خطط وملاحظات الدروس
tests/            اختبارات Playwright
files.json        ترتيب تحميل ملفات JS
build.py          سكربت البناء
VERSION           رقم الإصدار
```

## الخصوصية ومفتاح Gemini

- المفتاح اختياري، ويُحفظ في متصفحك فقط ولا يُرسل إلا إلى خدمة Gemini.
- لا يُضمَّن المفتاح في المشاريع المحفوظة ولا في الحزم.
- على جهاز مشترك اضغط **🗑 حذف المفتاح** في تبويب التشغيل عند الانتهاء.

## الاختبارات

```bash
pip install -r tests/requirements.txt
python -m playwright install chromium
python build.py
python -m pytest tests -v
```

الاختبارات تشغّل خادمًا محليًا وتفتح الصفحة في Chromium، ولا تحتاج إنترنت ولا مفاتيح. شغّل `python build.py` أولًا لأن أحد الاختبارات يفتح نسخة الملف الواحد من `dist/`.

للتسريع شغّل الاختبارات على عدة عمليات (كل عملية بمتصفحها وخادمها):

```bash
python tests/run_parallel.py        # عدد العمليات = min(عدد الأنوية، 4)
python tests/run_parallel.py 3 -k mouth   # 3 عمليات، وما بعده يُمرَّر إلى pytest
```

أو شريحة واحدة يدويًا: `TEST_SHARDS=3 TEST_SHARD=0 python -m pytest tests`. التوزيع حتمي ومتوازن بأوزان تقريبية في `tests/conftest.py` (`WEIGHTS`)، ويعتمد CI عليه في 3 مهام متوازية. عند إضافة اختبار ثقيل (أكثر من 10 ثوانٍ) أضف وزنه هناك ليبقى التوازن جيدًا.
